 **Solitaire – WPF Application (.NET 9)**

This project is a fully playable Solitaire game built using C, WPF, and .NET 9.  
It includes multiple difficulty modes, a login/guest system, Vegas mode with age validation, a help screen, and full backend logic for card movement, scoring, and win/loss tracking.

The application is deployed using ClickOnce, allowing simple installation and automatic updates.

---

 **Features**

- Full Solitaire gameplay (Klondike rules)  
- Easy and Medium difficulty modes  
- Vegas mode with balance tracking (18+ only)  
- Login system with age validation  
- Guest mode  
- Help / How‑to‑Play screen  
- Win/loss tracking  
- Click‑to‑move card interaction  
- Clean WPF interface with responsive layout  
- ClickOnce deployment with auto‑updates

 **Installation (ClickOnce)**

1. Download the setup folder from the provided installation link.  
2. Run the setup file (Windows may show a security prompt — choose Run).  
3. ClickOnce will automatically download the full application and required dependencies.  
4. When installation completes, the game will launch automatically.  
5. A desktop shortcut and Start Menu entry will be created for future use.

---

 **How to Play**

- Move cards by clicking (click‑to‑move system)  
- Build foundations from Ace → King  
- Use the stockpile to draw new cards  
- Reset the game at any time  
- Enable Vegas mode for balance‑based scoring (18+ only)  
- Use the [?] button in the top‑right corner for full instructions  

---

 **Known Issues / Limitations**

- Drag‑and‑drop movement is not implemented (click‑to‑move only).
- UI layout may appear slightly off or unfinished when the game is in full‑screen mode.
- The Help button is functional but may be less noticeable for users with reduced vision, depending on screen size and accessibility needs.
